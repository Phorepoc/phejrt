# Java runtime (MIDP 2.1)

Runs MIDlets: the small Java applications written for feature phones. It is the free **phoneME** runtime
(CLDC 1.1 and MIDP 2.1, GPL-2.0), with its platform layer written for Phorepoc: the window server, keys and touch,
fonts, files and record stores.

- Install a MIDlet suite as an ordinary package. Each MIDlet appears in the menu with its own name and icon and starts
  like any other application.
- Records (RMS) are kept under `C:\phejava`.
- Not included: networking, sound, push and the optional JSRs (Bluetooth, location, M3G ...). Not a certified Java
  implementation.

The licences and the written source offer are installed with the package in `\resource\phejava\licences\`.
