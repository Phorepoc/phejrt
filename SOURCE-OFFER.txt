phoneME Java runtime for Phorepoc -- licence notice and source offer

This package contains the phoneME Feature runtime built for Phorepoc OS: the CLDC-HI 1.1 virtual machine (portable C
interpreter), the MIDP 2.1 stack, their class libraries romized into the executable (phemidp.exe), and our own "javacall"
port of the platform layer (windowing, input, files, timers, fonts). phoneME is copyright Sun Microsystems, Inc. and is
licensed under the GNU General Public License version 2 only (GPL-2.0), as is everything else in this package. The built-in
bitmap fonts are glyphs rendered from DejaVu Sans Mono (Bitstream Vera licence, notice in NOTICE). The licence texts are
installed with the package in \resource\phejava\licences\.

Corresponding source, available to anyone who has this package, for at least three years after the release you installed
it from:

  1. The unmodified upstream source, pinned by commit in sources.lock of the repository below (the phoneME tree from
     https://github.com/magicus/phoneME at commit 5a13f65cff07b2211b7b867c51ada4bb9c7d4f32).
  2. Our changes to it (patches/), our own files (javacall/phehost, os/src, registry), and the scripts that fetch, patch,
     build and package the runtime and the MIDlet-suite packages:
       https://github.com/Phorepoc/phejrt   (the release tag of this package)
     with the toolchain images and build tools in https://github.com/Phorepoc/toolchain and https://github.com/Phorepoc/pdk.

A MIDlet suite installed on top of this runtime is not part of it: it is the work of its own author and carries its own
licence. Its package only holds the suite, a small launcher and the application registration.

Written offer: if the links above are no longer available, send a request to the address given on the Phorepoc
organisation page https://github.com/Phorepoc and we will send you the corresponding source on a medium of your choice
for the cost of the medium.
